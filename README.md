# Ghost School (Phaser 3)

A tower defense game built with Phaser 3, ported from the original LibGDX version.

## Gameplay

You are a wizard trying to survive in a ghost-infested school. Occupy beds to generate coins, build defenses, and survive as long as possible.

- **Move** your character using arrow keys (or WASD) or on-screen buttons
- **Find a bed** and click the bed icon to occupy it
- **Build defenses**: guns (attack the ghost) and electricity generators (produce resources)
- **Upgrade** your home, door, guns, and generators to survive stronger ghosts
- **8 AI robots** will automatically find beds and build defenses
- **The Ghost** gets stronger each time it returns home - survive as long as you can!

### Resources
- **Coins** - generated by occupied homes, used for building and upgrading
- **Electricity** - generated by electricity buildings, used for advanced upgrades

## Getting Started

```bash
npm install
npm start
```

This opens the game at `http://localhost:8080`.

## Build

```bash
npm run build
```

Output is in the `dist/` directory.

## Controls

| Key | Action |
|-----|--------|
| Arrow Keys / WASD | Move player |
| On-screen buttons | Move / Build / Upgrade |
| Eye button | Switch to eye (spectator) view |
| Player button | Switch back to player view |
| Green circle | View ghost location |
| Bed icon | Enter bed (when near one) |

## Tech Stack

- [Phaser 3.60](https://phaser.io/) - Game framework
- Webpack - Bundler
